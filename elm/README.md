# Elm implementation

Headless Elm (`Platform.worker`) doing RSI precomputation, timeline assembly,
the timed simulation loop, metrics, and the terminal chart. A small Node host
only reads the CSVs and supplies a monotonic clock, since Elm has no file or
clock access.

## Run the test suite

```sh
cd elm
elm-test
```

(or `npm test`)

## Run the evaluation

Build first, then run:

```sh
cd elm
elm make src/Main.elm --output=elm.js --optimize
node runner.cjs
```

(or `npm start`, which builds and runs)

The program prints the five metrics, the loop-only `sim time`, and a colored
two-series chart inside an 80×25 character budget.

## Build commands

```sh
elm make src/Main.elm --output=elm.js --optimize   # production bundle
elm make src/Main.elm --output=elm.js              # faster debug bundle
elm-test                                           # unit tests
```

`elm` and `elm-test` (0.19.1) plus Node 18+ are required. The runner depends on
`../data/meta.json` and the 20 `../data/*-USDT.csv` files generated by
`download_kucoin.ts`.

## Architecture

| Module | Role |
| --- | --- |
| `Main.elm` | Ports, decode, worker lifecycle, timing handshake |
| `Domain.elm` | Shared types for coins, signals, positions, trades |
| `Rsi.elm` | Wilder-smoothed 14-period RSI |
| `Strategy.elm` | Swappable RSI thresholds and buy strength |
| `Market.elm` | Sorted union timeline, hour→step map, per-step bar buckets |
| `Simulator.elm` | The timed step loop (fees, one position, ranking, gaps) |
| `Metrics.elm` | Beat-market, Sharpe, win/loss, avg gain, avg hold |
| `Chart.elm` | Two colored soft-line series in a box frame |
| `Format.elm` / `Report.elm` | Fixed-point formatting and the 80×25 layout |

### Timing handshake

1. Host sends `dataset`; Elm decodes and prepares everything untimed.
2. Host calls `performance.now()`, sends `run`, and Elm executes the whole
   `Simulator.run` fold synchronously in that update.
3. Host measures the elapsed monotonic time and sends it back via `simTime`.
4. Elm formats the report and emits it on `output`; the host prints it.

Everything excluded by the spec (CSV parsing, timeline, RSI, market index,
statistics, printing) happens outside that measured window.
